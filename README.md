## 📌 프로젝트 소개

**캐치! 수학 몬스터즈**는 초등학생이 수학 과목에 보다 쉽고 재미있게 접근할 수 있도록 제작한 학습 사이트입니다.  
디지털 교과서 기반의 학습 흐름에 캐릭터와 스토리 요소를 더해, 학습 과정이 지루하지 않도록 구성했습니다.

## ✨ 주요 구현 내용

### 1. 메인 페이지
- 캐릭터 애니메이션과 마우스 오버 효과를 적용해 시각적인 재미를 높였습니다.
- **탑 버튼** 클릭 시 페이지 상단으로 부드럽게 이동하도록 구현했습니다.
- **무료체험 버튼 / 하단 배너** 클릭 시 로그인 여부에 따라 이동 페이지가 달라지도록 처리했습니다.
  - 미로그인: 로그인 페이지 이동
  - 로그인 상태: 학습하기 페이지 이동

  ![메인](https://github.com/user-attachments/assets/bcdf5703-fea3-4d50-a6eb-0655de2c5cfe)

### 2. Header
- `React Router`를 사용해 페이지 간 이동을 구현했습니다.
- 학습하기 페이지에서는 Header가 보이지 않아야 했기 때문에, `useState`와 조건부 렌더링을 사용해 노출 여부를 제어했습니다.
- 로고 클릭 시 메인 페이지 상단으로 이동하도록 처리했습니다.
- 학습하기 / 학부모 코너 페이지는 로그인 상태를 확인한 뒤 접근 가능하도록 구현했습니다.
  - 미로그인: `"로그인해주세요"` 알림 후 로그인 페이지 이동
  - 로그인 상태: 해당 페이지 진입

### 3. 로그인 및 회원가입
- 로그인은 **Kakao Login API**를 활용해 구현했습니다.
- API 호출을 통해 사용자 정보를 받아오고, `App.jsx`를 통해 필요한 페이지에 전달할 수 있도록 구성했습니다.
- 토큰을 관리해 인증 상태를 유지할 수 있도록 처리했습니다.
- 로그인 후에는 로그인/회원가입 버튼 대신 **유저 이름이 표시된 프로필 뱃지**가 노출되도록 구현했습니다.
- 프로필 뱃지 클릭 시 유저 이름, 사진, 보유 포인트, 로그아웃 버튼이 포함된 팝업이 나타나도록 제작했습니다.

![로그인](https://github.com/user-attachments/assets/f23a7af0-ffc4-4076-b91b-0f31e30c3e76)

### 4. 탭 메뉴
탭 메뉴는 사용되는 위치와 특성에 따라 **두 가지 방식**으로 구현했습니다.

#### 4-1. 알림나무 / 학부모 코너
- URL 기반으로 탭 메뉴를 구현했습니다.
- `useLocation`과 `split`을 활용해 현재 URL을 가져온 뒤,
  현재 경로와 일치하는 메뉴의 스타일과 링크가 변경되도록 처리했습니다.

#### 4-2. 학습하기(도움말)
- `useState`를 활용해 탭 메뉴 기능을 구현했습니다.
- 현재 선택된 텍스트와 지정된 데이터를 비교해 페이지가 전환되도록 구성했습니다.
- 클릭한 리스트의 `id`와 데이터 `id`를 비교해 스타일이 변경되도록 구현했습니다.

![탭메뉴](https://github.com/user-attachments/assets/be6abb3d-08a6-4bf5-9acc-20aa49d62b2b)

### 5. 학습하기 - 도움말
- 도움말 영역의 콘텐츠는 `Swiper` 라이브러리를 사용해 구현했습니다.
- 슬라이드 형식으로 안내 내용을 보다 직관적으로 확인할 수 있도록 구성했습니다.

![도움말](https://github.com/user-attachments/assets/0a18137d-372f-4441-835d-c90486e006ec)

### 6. 사이트 소개 페이지

- CSS를 모듈화해 스타일을 보다 효율적으로 관리할 수 있도록 구성했습니다.

![사이트소개](https://github.com/user-attachments/assets/1e37db6c-b354-4242-8062-dd46aa924c5b)

## 💭 트러블슈팅

### 1. 로그인 후 UI가 바로 갱신되지 않던 문제
로그인 실행 후에도 로그인 페이지에 그대로 남아 있거나,  
프로필 뱃지가 즉시 활성화되지 않는 문제가 있었습니다.

원인을 확인한 결과, 로그인 후 화면이 새로 갱신되지 않아 발생하는 문제라고 판단했습니다.  
이를 해결하기 위해 로그인 함수 내부에서 `window.location.href`를 사용해 메인 페이지 URL로 이동하도록 처리했고,  
그 결과 로그인 직후 UI가 정상적으로 반영되도록 수정했습니다.


### 2. 도움말 탭 메뉴의 초기 스타일 미적용 문제
알림나무 / 학부모 코너 탭 메뉴는 URL 변경에 따라 즉시 스타일이 반영되었지만,  
도움말 페이지는 사용자가 직접 클릭해야만 초기 스타일이 적용되는 문제가 있었습니다.

이 문제를 해결하기 위해 `useRef`와 조건문을 활용한 추가 함수를 작성했고,  
초기 진입 시에도 올바른 탭 스타일이 적용되도록 개선했습니다.

## 🌱 배운 점

- 하나의 기능도 페이지 성격에 따라 다른 방식으로 구현할 수 있다는 점을 경험했습니다.
- `React Router`, `useState`, `useLocation`, `useRef` 등을 활용하며 상태와 URL 기반 UI 제어 방식을 익힐 수 있었습니다.
- 로그인 기능 구현 과정에서 사용자 인증 상태를 관리하고, 조건에 따라 페이지 접근을 제어하는 방법을 배울 수 있었습니다.
