## 📌 프로젝트 소개

**캐치! 수학 몬스터즈**는 초등학생이 수학 과목에 보다 쉽고 재미있게 접근할 수 있도록 제작한 학습 사이트입니다.

## ✨ 주요 구현 내용

### 1. 메인 페이지
- 캐릭터 애니메이션과 마우스 오버 효과를 적용해 시각적인 재미 향상
- **탑 버튼** 클릭 시 페이지 상단으로 부드럽게 이동하도록 구현
- **무료체험 버튼 / 하단 배너** 클릭 시 로그인 여부에 따라 이동 페이지가 달라지도록 처리
  - 미로그인 → 로그인 페이지 이동
  - 로그인 → 학습하기 페이지 이동

  ![메인](https://github.com/user-attachments/assets/bcdf5703-fea3-4d50-a6eb-0655de2c5cfe)

### 2. Header
- `React Router`를 사용해 페이지 간 이동을 구현
- 학습하기 페이지에서는 Header가 보이지 않아야 했기 때문에, `useState`와 조건부 렌더링을 사용해 노출 여부를 제어
- 로고 클릭 시 메인 페이지 상단으로 이동하도록 처리
- 학습하기 / 학부모 코너 페이지는 로그인 상태를 확인한 뒤 접근 가능하도록 구현
  - 미로그인: `"로그인해주세요"` 알림 후 로그인 페이지 이동
  - 로그인 상태: 해당 페이지 진입

### 3. 로그인 및 회원가입
- **Kakao Login API**를 활용해 로그인 구현
- API 호출을 통해 사용자 정보를 받아오고, `App.jsx`를 통해 필요한 페이지에 전달
- 토큰을 관리해 인증 상태를 유지할 수 있도록 처리
- 로그인 후에는 로그인/회원가입 버튼 대신 **유저 이름이 표시된 프로필 뱃지**가 노출되도록 구현
- 프로필 뱃지 클릭 시 유저 이름, 사진, 보유 포인트, 로그아웃 버튼이 포함된 팝업이 나타나도록 제작

![로그인](https://github.com/user-attachments/assets/f23a7af0-ffc4-4076-b91b-0f31e30c3e76)

### 4. 탭 메뉴
탭 메뉴는 사용되는 위치와 특성에 따라 **두 가지 방식**으로 구현

#### 알림나무 / 학부모 코너
- URL 기반으로 탭 메뉴를 구현
- `useLocation`과 `split`을 활용해 현재 URL을 가져온 뒤,
  현재 경로와 일치하는 메뉴의 스타일과 링크가 변경되도록 처리

#### 학습하기(도움말)
- `useState`를 활용해 탭 메뉴 기능을 구현
- 현재 선택된 텍스트와 지정된 데이터를 비교해 페이지가 전환되도록 구성
- 클릭한 리스트의 `id`와 데이터 `id`를 비교해 스타일이 변경되도록 구현

- 슬라이드 형식으로 안내 내용을 보다 직관적으로 확인할 수 있도록 구성

## 💭 트러블슈팅

### 1. 로그인 후 UI가 바로 갱신되지 않는 문제
로그인 실행 후에도 로그인 페이지에 그대로 남아 있거나,  
프로필 뱃지가 즉시 활성화되지 않는 문제가 발생.

원인 확인 결과, 로그인 후 화면이 새로 갱신되지 않아 발생하는 문제로 판단.  
이를 해결하기 위해 로그인 함수 내부에서 `window.location.href`를 사용해 메인 페이지 URL로 이동하도록 처리,  
그 결과 로그인 직후 UI가 정상적으로 반영되도록 수정.

### 2. 도움말 탭 메뉴의 초기 스타일 미적용 문제
알림나무 / 학부모 코너 탭 메뉴는 URL 변경에 따라 즉시 스타일이 반영되었지만,  
도움말 페이지는 사용자가 직접 클릭해야만 초기 스타일이 적용되는 문제가 발생.

이 문제를 해결하기 위해 `useRef`와 조건문을 활용한 추가 함수를 작성,  
초기 진입 시에도 올바른 탭 스타일이 적용되도록 개선.
